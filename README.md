# Ц.Е.Н.Т.Р. — Tactical Shooter Demo

Демонстрационный сайт страйкбольного клуба «Ц.Е.Н.Т.Р.» (Саратов).

## О проекте

Это интерактивная HTML/CSS/JavaScript-концепция сайта, подготовленная для предварительного просмотра и согласования дизайна. В проекте сохранены анимации и интерактивные элементы, в том числе вступительная заставка с лазерными лучами, прицелом и тактическим интерфейсом.

**Важно: это демонстрационный макет, а не готовый к коммерческому запуску сайт.** Перед публикацией для клуба необходимо проверить и согласовать тексты, цены, контакты и остальные сведения.

## Что пока является демонстрацией

- Фотографии загружаются с Unsplash и должны быть заменены на согласованные фотографии клуба.
- Форма записи не отправляет заявки. При отправке она показывает уведомление о демонстрационном режиме.
- Блок карты является местом для будущей интеграции карты.
- Внешние шрифты и иконки подключаются через Google Fonts и cdnjs, поэтому для их загрузки требуется интернет.
- Анимации могут быть отключены или упрощены настройками доступности устройства (`prefers-reduced-motion`).

## Как посмотреть локально

Откройте `index.html` в современном браузере. Для публикации через GitHub Pages достаточно загрузить файлы репозитория и включить Pages для ветки `main`, папка `/ (root)`.

## Использование

Материалы предназначены для демонстрации концепции заказчику. Не используйте макет как подтверждение того, что онлайн-запись, карта или иные внешние сервисы уже подключены. Перед реальным запуском согласуйте контент и отдельно настройте необходимые интеграции.
